# APAS : BREACH

A browser-based simulation game about data centre water use 
and the decisions that keep a city running overnight.

Built with React · TypeScript · Three.js · Zustand · Web Audio API

## Run locally

npm install
npm run dev

## Structure

/docs        — design system, copy, and full spec
/src/game    — simulation engine, levels, audio
/src/components — landing page and game UI

## Rules

- No copyrighted assets
- No audio samples — all sound is Web Audio API synthesised
- No references to restricted academic terms
  anywhere in code or UI
